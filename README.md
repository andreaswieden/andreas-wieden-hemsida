# Andreas Wieden – personlig hemsida

En enkel, responsiv personlig hemsida på svenska byggd med HTML och CSS.

## Innehåll
- Kort presentation av Andreas Wieden
- Undervisning och datateknik på Chalmers
- Projektbaserat lärande och handledning
- Intressen: bordtennis och schack
- Länk till GitHub-profilen

## Visa sidan lokalt
Öppna `index.html` i en webbläsare. Ingen byggprocess eller externa bibliotek behövs.

## Publicera med GitHub Pages
1. Öppna **Settings** för repot.
2. Gå till **Pages**.
3. Under **Build and deployment**, välj **Deploy from a branch**.
4. Välj grenen `main` och mappen `/ (root)`, och spara.
5. När publiceringen är klar visas sidans webbadress under Pages.

## Integritet
Sidan innehåller endast en yrkesmässig presentation och några allmänna intressen. Ingen privat kontaktinformation eller familjeinformation publiceras.
